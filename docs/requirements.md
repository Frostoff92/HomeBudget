# HomeBudget

## Purpose

HomeBudget is a household expense tracking application.

The application should help:
- track household expenses;
- separate regular and one-time expenses;
- analyze spending by store and category;
- compare actual spending against a monthly budget;
- forecast regular expenses;
- import historical expense data.

## MVP

Version 0.1 should support:

- expense date;
- store;
- amount;
- category;
- expense type:
  - regular
  - one_time
  - unknown
- optional notes;
- historical data import from CSV;
- totals by:
  - period
  - category
  - store
  - expense type.

## Current dataset

The initial staging dataset contains:

- 139 expense records;
- total expenses: 3596.91 EUR;
- regular expenses: 818.11 EUR;
- one-time expenses: 2731.31 EUR;
- unknown expenses: 47.49 EUR.
