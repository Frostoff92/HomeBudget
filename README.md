# 🏠 HomeBudget

**HomeBudget** — учебный проект на Go для учёта и анализа семейных расходов на основе реальных чеков. Проект развивается поэтапно: обработка CSV → модели данных и валидация → PostgreSQL → тестирование и контейнеризация → GitLab CI.

> **Статус:** в разработке (MVP). Репозиторий приватный. Реальные данные о покупках хранятся локально и не предназначены для публикации.

## Задачи проекта

- Учёт расходов по чекам, магазинам, категориям и типам трат.
- Импорт записей из CSV, полученных из Excel.
- Детализация позиций чеков (*Items*) и связка с чеками по `Receipt ID` — следующий этап.
- Аналитика расходов по магазинам, категориям и периодам.
- Практика Go, PostgreSQL, Docker, автоматизированного тестирования и GitLab CI.

## Что уже работает

- Структура `Purchase` с ID, датой, магазином, суммой в центах, категорией и типом расхода.
- Проверка обязательных полей через `Purchase.Validate()`.
- Подсчёт общей суммы валидных покупок и суммы по выбранному магазину.
- Открытие CSV с разделителем `;`, чтение заголовка, отдельная обработка первой покупки и чтение оставшихся записей через `ReadAll()`.
- Преобразование даты CSV в `time.Time` через `time.Parse("2006-01-02", ...)`.
- Экспериментальный импорт пяти записей в `[]Purchase` с проверкой числа полей, разбором суммы и даты, `Validate()` и `append()`. Контрольный результат: **5 покупок, 64.73 EUR** (HB-000002—HB-000006).
- `parseMoney()` для денежных строк с десятичной запятой (`"2,05"` → `205`; `"38,2"` → `3820`) без `float64`.
- Проверки некоторых ошибочных денежных форматов, отрицательных значений и переполнения `int64`.
- **12 автоматических тестов**, успешно пройденных на текущем этапе разработки.

**Пока не реализовано:** единый импорт первой и последующих записей, обработка всего CSV без лимита в пять записей, статистика пропусков, проверка дубликатов и сверка итогов с Excel. Также впереди загрузка *Items*, PostgreSQL и GitLab CI pipeline.

## Источники данных

- `HomeBudget_Receipts_v2.xlsx` — реестр чеков.
- `HomeBudget_Items_v14.xlsx` — позиции покупок и связанные справочники.
- `receipts.csv` — локальный CSV-экспорт реестра, используемый во время разработки.

Для CSV используется разделитель `;`. Текстовые файлы необходимо сохранять в **UTF-8**, чтобы названия магазинов и товаров на болгарской кириллице не искажались. Суммы из Excel в евро с десятичной запятой преобразуются в целые центы (`int64`).

### Конфиденциальность

Реальные чеки и экспортированные CSV **не добавляются в Git**. В `.gitignore` следует исключить как минимум `receipts.csv` (и остальные локальные файлы с реальными расходами, если они появятся). Приватность репозитория не заменяет аккуратное обращение с исходными данными.

## Локальный запуск

Требуется установленный Go. Из корневой директории проекта:

```bash
go run .
```

Текущая учебная версия `main.go` ожидает локальный файл `receipts.csv` в рабочей директории. Первая покупка обрабатывается отдельно, а цикл импорта ограничен пятью следующими записями. Полноценный импорт всех чеков пока не реализован.

Запуск тестов:

```bash
go test -v .
```

Тестам `parseMoney()` и `Purchase.Validate()` внешний CSV не требуется.
